FM27 Face Generator – Patch notes (English)
==========================================
(Deutsch: PatchNotes_DE.txt)


Version 1.8.7.5
---------------
Fixes
- Switching light/dark no longer freezes the program (the window stayed empty). Also affected changing the
  language.
- Season +1 / ageing: every ageing now starts from the player's first face instead of the last aged image –
  images no longer get "wilder" every season. Already distorted images from 1.8.7.4 get their original face
  re-created on the next ageing.

New
- "Light ⇄ Dark" switch at the very top left.
- Save folder is now ...\graphics\faces\FM27 Face Generator (incl. backup). The old folder is moved there
  automatically on first start; "Undo" keeps working.
- "Re-roll" also works for images in the game (FaceDrop): new face at the same age, same file name, old image
  backed up first (can be undone).
- Player list: detects players that already have an image (save folder, or by UID in FaceDrop) –
  "Only without image" skips them.
- "New": players from the player list sorted alphabetically by surname.
- Drag the tabs "New / Gallery / Player list" with the mouse to reorder them (saved).
- AI tab: fast mode for Lightning models (about twice as fast, slightly less detail – for testing).
- timing.log now also lists the Forge settings per image (size, steps, sampler).


Version 1.8.7.4
---------------
Ageing set
- The file name gets the new age: "…_16J_…" becomes "…_20J_…" (instead of appending "_mit20").
- Age several images at once: select them (Ctrl/Shift, "Select all" or Ctrl+A).
- New spin box "or older by … years": every selected image gets e.g. 4 years older, whatever its age was.

Replace in game (Gallery → FaceDrop)
- "Replace in game" tick box: the new image replaces the FaceDrop image, FM shows it right away. With several ages
  the lowest one goes into the game.
- Old images are backed up first (save folder\Sicherungskopie\…), "Undo last replacement" restores them.
- For large batches (also overnight): one question at the start, all images first go to a queue, then into the
  game all at once; failures are retried once, a summary is shown at the end.
- "Season: career +1 year" – the whole career one year older with one click.

Speed
- Remaining time in the status bar ("approx. 9 min left") and the average time per image at the end.
- Cut-out and saving now run in parallel while the AI already paints the next image.
- With local Forge the pause between images is skipped.
- Time measurement per image in %APPDATA%\FM27FaceGenerator\timing.log.

Interface
- New design with the green from the icon, plus a dark mode (button at the bottom right).


Version 1.8.7.3
---------------
- Drop-downs: typing now shows a suggestion list right below the field (like a browser search bar, at most 8
  entries visible). It stays open while you keep typing – the built-in list closed immediately on Windows.
  ↑/↓ selects, Enter confirms, Esc closes, clicking works too.
- Gallery → FaceDrop: new "Open" button next to the career selection opens the career's folder in Explorer
  (for "Real players" the FaceDrop folder).


Version 1.8.7.2
---------------
- All 211 FIFA countries available (previously 131), e.g. El Salvador, Cuba, Guatemala, Taiwan, Fiji, Moldova –
  each with a typical population mix. New ethnicity "Melanesian" (Papua New Guinea, Fiji, Solomon Islands …).
- Drop-downs: typing opens the list and jumps to the matching entry (e.g. "Ivo" → Ivory Coast). Arrow keys move
  within the list, Enter confirms, Esc closes.
- Typing in the personality field fixed: "Merc" + Enter now gives Mercenary. Clicking into the field selects the
  old text so typing replaces it.
- FaceDrop: duplicate images are detected after about 1–2 seconds (previously up to 30 s), the question appears in
  the foreground. The gallery is no longer rebuilt completely.
- Much faster start: the generator is now a program folder (EXE + _internal) instead of a single EXE that had to
  unpack itself on every start. "Update now" is faster too. Switch once manually (see README, section Updates).
- Task Manager and taskbar show "FM27 Face Generator" instead of "Python", with its own icon (player head +
  football) instead of the default icon.
- The generator starts directly in the foreground.


Version 1.8.7.1
---------------
- 20 languages: every language available in FM27 (except Arabic). New: Dutch, Danish, Norwegian, Swedish, Polish,
  Russian, Turkish, Greek, Indonesian, Chinese (Simplified), Spanish (Latin America) and Portuguese (Portugal).
- All translations except German are AI-generated and marked as such in the language selection,
  e.g. "English (AI-translated)".
- Country names of the new languages come from the ISO country list (not AI).
- Player list: country and personality names of the new languages are recognised on import; the column names of
  the new languages are estimated (not yet checked against real FM exports).
- Interface: "Tattoos from" has its own row, long texts in the Output tab wrap instead of being cut off – in all
  languages.


Version 1.8.7
-------------
(includes everything from test versions 1.8.1 – 1.8.4)

FaceDrop
- FaceDrop is detected automatically (Output tab → FaceDrop), even if your FM user data folder lives
  elsewhere via the Steam launch option user_data_location="…". If there are several FaceDrop folders, the one
  FaceDrop used last is taken. The folder can also be chosen by hand.
- Gallery: new switch "Show: Save folder | FaceDrop". With FaceDrop you see the images that are already in the
  game – per career or "Real players", with player ID.
- Ageing sets can be created from FaceDrop images (the new images go to your save folder).
- Your own images that are already in the game get a green check mark in the gallery (✓ in the game).
- Clean up duplicate images: once FaceDrop has taken over an image, your own copy can go to the Recycle Bin.
  Setting: Ask (default) / Clean up automatically / Off. Checked at startup and while running.
- Nothing in FaceDrop's folders is ever changed (read only) – rename, delete and re-roll are blocked there.

Usage
- New: "Copy (Ctrl+C)" – copies the image file like Explorer does. In FM hover over the portrait and press Ctrl+V.
- "Find FM folder" now also finds an FM user data folder moved via the Steam launch option and suggests the
  clearer folder ...\graphics\FM27 Face Generator.
- Status bar at the bottom: the text is no longer cut off (wraps if needed), the progress bar has a fixed width.

Updates
- Update notice with "Update now": downloads the new version, replaces the .exe and restarts
  (takes about 30–45 seconds). "Open download page" is still available.
- Test switch "Include test versions" (Output tab): the update notice then also offers test versions.
- New in the package: PatchNotes.txt and PatchNotes_DE.txt.


Version 1.8.0
-------------

Gallery
- Two tabs: "Newly created" (images of this session) and "Gallery" (all images in the save folder, with search).
- Newest images are always at the top.
- Drag and drop: drag images straight from the gallery into FM (FaceDrop) or Explorer, several at once too.
- Multi-select with Ctrl/Shift + click.
- Delete (Del) moves to the Recycle Bin, rename with F2 – ageing sets keep working afterwards.

Images
- New default file name: Country_AgeJ_Personality_ID (e.g. Netherlands_16J_Very-Ambitious_2106529392.png).
- Shirt: second colour, patterns (stripes, hoops, sash …) and club presets you can save.
- Personality now sits in the Player tab and can be typed (typing filters, Enter confirms).

Local Stable Diffusion (Forge)
- Forge can start and stop automatically with the generator.
- Real progress from Forge in the progress bar, otherwise it keeps moving smoothly.
- Fixed the false "API is off" alarm while Forge was starting.

Other
- Update notice at startup ("Yes, please" / "No, I want to play", a single version can be hidden).
